Detection Query Library

Production-tested detection queries, hunting thresholds, and audit rules across Splunk SPL, Sysmon XML, Windows Events, and IBM QRadar AQL.

Splunk SPL Event 4625 • T1110
Brute-Force & Password Spraying Threshold

Detects high-frequency failed logon attempts across single or distributed user accounts from internal or perimeter IP addresses.

index=windows EventCode=4625 | bin _time span=5m | stats count, dc(TargetUserName) as targeted_users by src_ip | where count > 10 OR targeted_users > 3
Splunk SPL Event 4104 • T1059.001
Obfuscated & Encoded PowerShell Execution

Flags base64 encoded scripts, download cradles, and execution policy bypass parameters inside PowerShell script block logs.

index=windows EventCode=4104 (ScriptBlockText="*-enc*" OR ScriptBlockText="*-EncodedCommand*" OR ScriptBlockText="*FromBase64String*" OR ScriptBlockText="*DownloadString*") | table _time, Computer, ScriptBlockText
Splunk SPL Event 4728/4732 • T1078
Privilege Escalation via Local Group Addition

Audits whenever a user account is granted administrative access by being added into privileged local or domain groups.

index=windows (EventCode=4728 OR EventCode=4732) TargetUserName="*Admin*" | table _time, SubjectUserName, TargetUserName, MemberName
Sysmon XML Sysmon Event 1 • T1059
Suspicious Process Spawning from %TEMP% or %APPDATA%

Identifies executable processes originating from atypical user-writable directories commonly leveraged by droppers and payloads.

<QueryList>
  <Query Id="0" Path="Microsoft-Windows-Sysmon/Operational">
    <Select Path="Microsoft-Windows-Sysmon/Operational">*[System[(EventID=1)]] and *[EventData[Data[@Name="CurrentDirectory"] and (contains(.,"AppData") or contains(.,"Temp"))]]</Select>
  </Query>
</QueryList>
Sysmon SPL Sysmon Event 3 • T1071
Abnormal Network Beaconing by Unknown Binaries

Detects outbound connections over non-standard ports (e.g. 4444, 5555, 8080) initiated by processes outside standard browsers.

index=sysmon EventCode=3 NOT (Image="*chrome.exe" OR Image="*firefox.exe" OR Image="*msedge.exe") DestinationPort IN (4444, 5555, 8080, 8443, 9001) | stats count by Image, DestinationIp, DestinationPort
Sysmon SPL Sysmon Event 11 • T1036.005
Masqueraded System File Creation in User Paths

Alerts when common Windows system file names (svchost.exe, lsass.exe, csrss.exe) are created outside C:\Windows\System32.

index=sysmon EventCode=11 TargetFilename IN ("*\svchost.exe", "*\lsass.exe", "*\taskhost.exe") NOT TargetFilename="C:\Windows\System32\*" | table _time, Image, TargetFilename
Windows Security Event 4624 / 4625 / 4740
Authentication & Account Lockout Monitoring

Key Windows Security log IDs: 4624 (Logon success with Type 2-Interactive, 3-Network, 10-RDP), 4625 (Failed logon), and 4740 (Account lockout).

index=windows EventCode IN (4624, 4625, 4740) | eval Status=case(EventCode==4624,"SUCCESS", EventCode==4625,"FAILURE", EventCode==4740,"LOCKED") | stats count by TargetUserName, Status, src_ip
Windows System System Event 7045 • T1543.003
New Windows Service Installation (Persistence)

Tracks new service creation entries in the Windows System event log, inspecting the ImagePath for suspicious script runners or temp paths.

index=windows source="WinEventLog:System" EventCode=7045 | table _time, ComputerName, ServiceName, ImagePath, ServiceType, StartType
QRadar AQL QRadar AQL • T1110
Rapid Multi-Account Authentication Failures

Correlates multiple failed authentications grouped by source IP address within a sliding 5-minute detection window in IBM QRadar.

SELECT "SourceIP", COUNT("EventID") AS "Failures", UNIQUE("UserName") AS "TargetUsers" FROM events WHERE "EventID" = 4625 GROUP BY "SourceIP" HAVING "Failures" > 15 LAST 5 MINUTES
QRadar AQL QRadar AQL • T1078
Off-Hours Administrative Privilege Use

Filters successful administrative sessions occurring outside standard business hours (between 22:00 and 06:00).

SELECT UTF8(payload), "UserName", "SourceIP", "LogonType" FROM events WHERE "EventID" = 4624 AND "LogonType" = 10 AND DATEFORMAT("DeviceTime", 'HH') IN ('22','23','00','01','02','03','04','05') LAST 24 HOURS
