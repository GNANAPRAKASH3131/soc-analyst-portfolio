Detection Query Library

Splunk SPL

Detects encoded PowerShell executions hiding reverse shells or stagers:

index=windows sourcetype="XmlWinEventLog:Microsoft-Windows-Sysmon/Operational" EventCode=1 Image="*\powershell.exe"
| where match(CommandLine, "(?i)-(enc|encodedcommand)\s+[A-Za-z0-9+/=]{20,}")
| table _time, host, User, CommandLine, ParentImage
Sentinel KQL

Identifies repeated failed logins followed by successful authentication:

DeviceLogonEvents
| where ActionType in ("LogonFailed", "LogonSuccess")
| summarize 
    FailedCount = countif(ActionType == "LogonFailed"),
    SuccessCount = countif(ActionType == "LogonSuccess")
    by AccountName, RemoteIP, bin(TimeGenerated, 15m)
| where FailedCount >= 5 and SuccessCount >= 1
Sigma Rule

Detects suspicious service installations often tied to persistence:

title: Suspicious Service Installation
logsource:
    product: windows
    service: system
detection:
    selection:
        EventID: 7045
        ImagePath|contains:
            - '\AppData\Local\Temp\'
            - '\Users\Public\'
            - 'powershell'
    condition: selection
level: high
